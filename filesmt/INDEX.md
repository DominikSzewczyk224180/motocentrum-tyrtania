## 🎯 SCENARIUSZE UŻYCIA

### Scenariusz 1: "Dopiero zaczynasz"
1. Przeczytaj **README.md** (10 min)
2. Uruchom lokalnie używając **QUICK-START.md** (5 min)
3. Przejrzyj kod w **index.html** i **style.css**
4. Zmień coś prostego (np. kolor, tekst) i zobacz efekt
5. Gotowy do dalszej pracy!

### Scenariusz 2: "Chcę pokazać klientowi"
1. Wdróż na GitHub Pages używając **DEPLOYMENT.md** (15 min)
2. Przetestuj na telefonie, tablecie, komputerze
3. Przeczytaj **CHECKLIST-SPOTKANIE.md** (20 min)
4. Wydrukuj **OFERTA-DLA-KLIENTA.md**
5. Umów spotkanie!

### Scenariusz 3: "Klient powiedział TAK!"
1. Podpisz **UMOWA-SZABLON.md**
2. Weź zaliczkę 50%
3. Zbierz materiały (zdjęcia, teksty)
4. Sprawdź **ROADMAP.md** co robić dalej
5. Zacznij kodować dodatkowe strony (oferta.html, kontakt.html)

### Scenariusz 4: "Projekt gotowy, co dalej?"
1. Sprawdź **ROADMAP.md** - Faza 3 i 4
2. Zaproponuj klientowi panel admin (+1000 zł)
3. Zaproponuj SEO i blog (+800 zł)
4. Długoterminowa współpraca = stały dochód!

## 🆘 POMOC

Jeśli coś nie działa:

1. **Sprawdź Console** (F12 w przeglądarce)
2. **Przeczytaj error message**
3. **Google** - większość problemów została rozwiązana
4. **Stack Overflow** - zadaj pytanie

**Najczęstsze problemy:**
- Ścieżki do plików (relative paths)
- CORS errors (używaj live servera)
- JSON parsing (sprawdź składnię)
- CSS nie działa (sprawdź specificity)
